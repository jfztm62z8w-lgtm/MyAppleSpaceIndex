# MyAppleSpace — Relaunch Landing Page

A simple single-page site announcing the relaunch of myapplespace.com, a community for Apple users.

## What's here

- `index.html` — the landing page. Self-contained (no external dependencies), so it's ready to deploy as-is.

## Deploying with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under "Build and deployment," set the source branch to `main` and the folder to `/ (root)`.
4. GitHub will publish the site at `https://<your-username>.github.io/<repo-name>/` within a couple of minutes.

## Notes

- The "Keep me posted" form uses a `mailto:` action, so submissions open an email draft rather than going to a server — no backend required.
- This is a temporary/staging deployment. Update the contact email in `index.html` if needed before sharing widely.
